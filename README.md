# 🎈 Blank app template

A simple Streamlit app template for you to modify!

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/)

## Features

- Streamlit web application framework
- HubSpot MCP (Model Context Protocol) integration

### How to run it on your own machine

1. Install the requirements

   ```
   $ pip install -r requirements.txt
   ```

2. Run the app

   ```
   $ streamlit run streamlit_app.py
   ```

### HubSpot MCP Setup

This project includes configuration for HubSpot integration via Model Context Protocol (MCP). This allows AI assistants to interact with your HubSpot CRM data.

See [MCP_SETUP.md](MCP_SETUP.md) for detailed setup instructions.
